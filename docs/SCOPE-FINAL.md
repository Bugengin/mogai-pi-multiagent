# 范围与剩余事项最终确认（个人本地使用）

日期：2026-11-23
定位：**个人本地、单用户、非公网服务**。
状态：核心功能已完成，无必须解决的核心阻塞问题；剩余事项均为历史复现、统计增强与模型能力优化。

> 一句话定位：**个人本地使用场景下，系统已经基本完成；剩余是历史复现、统计增强和模型能力优化，不再有必须解决的核心阻塞问题。**

## 一、范围外的生产化事项（当前不实现）

个人本地、单用户、非公网项目下，以下生产化问题**不属于当前任务范围**：

| 生产化事项 | 处理 |
| --- | --- |
| 登录、权限和多用户隔离 | 不实现 |
| PostgreSQL 或其他生产数据库 | 不迁移，继续使用 SQLite |
| 公网部署和反向代理 | 不做 |
| 多租户数据隔离 | 不做 |
| 高可用中转和自动故障切换 | 不做（依赖外部中转） |
| Secret Manager、密钥轮换平台 | 不做（本地凭据文件） |
| 生产级备份恢复体系 | 不做 |
| 长期监控、报警和运维平台 | 不做 |

因此，当前的 SQLite、本地凭据文件、`127.0.0.1` 绑定以及外部中转依赖，在个人项目范围内均**可以接受**。

## 五、口径强调（避免误读）

| 指标 | 含义 |
| --- | --- |
| **55%** | R004 原始模型运行（run_2263d1062f41）的**字面评分**：11/20 |
| **95%** | 同一批输出的**语义评分离线复评**：19/20，复用已有输出、未重新调用模型 |
| **53.3%** | R004 三轮聚合（32/60）的**字面口径**，含评分器同义词误差 |

> **不要把 95% 直接描述成真实模型重新运行的准确率。** 正确表述始终是：
> `55% = 原始模型运行的字面评分；95% = 同一批输出的语义评分复评。`
